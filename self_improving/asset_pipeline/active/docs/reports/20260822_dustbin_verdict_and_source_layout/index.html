11如实记录

--only 覆写事故：校准器带 --only 时不读旧表，一次外部资产战役把 534 条原生行静默清空。跑前备份救了场；已修（--only=重测指名保留其余），教训写进代码注释。
声明自证循环：第二轮复验从 overrides 读「声明」，而 overrides 已被第一轮的躺姿覆写——等于拿躺姿验躺姿得出「可信」。去污后改从账本 fragment 取声明。
度量错误自纠：早期用「与 upright 四元数夹角」判躺立，把绕竖轴的 yaw 也计入（85° 实为站立+偏航）。改用 up 轴倾角度量后复核了全部关键判定。
校准环境失配（开放）：同一资产贴面出生，裸地面翻倒、场景桌面站住——校准器地面材质与消费运行时不一致，根治=校准场景用桌面材质（见第 12 节）。
真问题两枚（非判据问题）：002_bowl、021_cup 在 4500 步后仍在动（碗内滚动极限环嫌疑），需单独处置。
测量脚手架小事故：全库网格普查单进程 OOM（拆每资产子进程后过）；后台启动把「写脚本+执行」整链后台化写出 0 字节文件（改为写完校验再启动）。
