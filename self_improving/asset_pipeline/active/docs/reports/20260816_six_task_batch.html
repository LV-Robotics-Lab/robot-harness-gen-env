4 · 分任务详解

任务 1 · 模型级颜色选型落生产 commit 8789f33

问题：110_basket 一个资产下有黄/红/白三个 model，资产级颜色标签永远「色盲」。E1 实验已证模型级选型把颜色真命中从 9 提到 23，但那是 /tmp 补丁——本任务把它变成生产代码。

链路：账本 appearance.colors_measured →（gen_fragment 投影）→ 视图片段模型级 colors →（s9 注入 + 上游 CatalogModel.colors 新字段）→ grounding 模型级判分：命中 +4.0，实测颜色明确缺失则整 model 拒绝，无颜色信息的按上游设计走着色回退。

$ ground_object(yellow basket / red basket / red cup)   # 生产目录实跑，seed=42
yellow basket -> 110_basket m1  colors=['yellow']
   rejected: 110_basket m0: model colors ['orange','red'] lack yellow
             110_basket m2: model colors ['red'] lack yellow
red basket    -> 110_basket m0  colors=['orange','red']
red cup       -> 301_cup   m0  colors=['brown','red']

三条生产选型的机读结果：归档 coverage reports。

why：颜色是 model 的属性不是资产的属性——同资产三个篮子三种颜色。片段实测 72 个 model 里 62 个已带模型级颜色。

任务 3 · 23 个 model 许可回填 commit 4212191

做法：不硬编 SPDX 码——22 个 NVIDIA Isaac Props 资产按判例落条款原文（无对应 SPDX 码，spdx: null 如实留空 + terms_note 记要点 + evidence_url），1 个 Objaverse 资产带机读 by-sa 标签，落 CC-BY-SA-4.0。回填后片段统计实测 unknown_license_models: 0。

// 314_cabinet 判例（22 个同源资产沿用）
"spdx": null, "status": "declared",
"terms_note": "NVIDIA Isaac Sim Additional Software and Materials License
  (v. June 9, 2025): internal R&D use permitted (License FAQ: free for
  internal R&D); modification/redistribution prohibited (Sec 2.2/2.4)"
要知道的边界：这 22 个的条款是「内部研发可用、禁止再分发」。将来若要对外发布数据集/资产包，这 22 个不能随包分发——账本里查 spdx null + NVIDIA wording 即可全部筛出。

任务 4 · settle 失败资产修复 commit 4212191

问题：尺寸方案 C 重定标后 4 个 model settle 复检失败。旧判据看全程位移——但缩到真实 2.5cm 的樱桃会滚，滚不等于没停。

做法：换成「停没停」判据（1500 步后取末 100 步位移 < 2mm，250Hz），并借标定战役的多起始姿态重试（默认姿态 + 单位四元数 + 4×90° 翻转）；成功后把默认稳定姿态改成实测静止姿态（pose_id=measured_rest），z_policy 按实测静止时原点高度重定。

333_cherry m0: pass (measured_rest, origin_on_table)   # 滚→停，正常物理
341_tool   m0: pass (measured_rest, origin_on_table)
345_alarm  m0: pass (measured_rest, center_on_table)
356_ahead  m0: FAIL —— 5 种起始姿态末窗位移均 >2mm，保持剔除
why：判据换的是「测什么」不是「放多松」——ahead 在同一判据下照样死，说明它真的立不住（卷帘薄片永续晃动），不是判据放水。

9 · 收尾：术语与依赖

ledger（账本）=每资产一份的 metadata 契约文件；verification digest=验证记录锚定的网格文件指纹，网格一变旧验证自动失效；settle=把资产放到支撑面上跑物理看它停不停得住；convexHull=用凸包近似碰撞体；RigidBodyAPI=USD 里声明「这是个受物理的刚体」的标记；末窗判据=只看最后一小段时间还动不动，容忍前期滚动；hyx=lab 仓的工作分支（本地）；镜像仓=huyuxinn/env-gen-dev，你自己的 GitHub 私仓。上游依赖：RoboTwin（SAPIEN 栈）、Isaac Sim 5.0（isaac-smoke conda env）、YCB/Objaverse/NVIDIA Isaac Props 资产源。局部细节见各目录 README 与 v3 成果页。
