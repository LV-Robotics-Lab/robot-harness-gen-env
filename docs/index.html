Acceptance contract
“看起来放好了”不是通过条件
静态 validator 证明几何和包自洽；真实回放才提供接触、稳定、可见性和视频证据。两套检查分开，不能用截图替代物理。
A
编译阶段先排除确定性的错误
这些检查不需要 RoboTwin checkout，pytest fixture 就能覆盖。它们保证 resolved scene 可序列化、可回放、关系不矛盾。
边界每个 object 恰有一条 support relation；support / axis 关系不能成环。
几何完整 source footprint 必须落进目标局部 stable surface，容器还要满足 interior AABB。
完整性资产文件存在、roundtrip digest 相同、package manifest 每个 SHA-256 对得上。
攻击测试锁住的误报外层 plate AABB 内的边缘摆放容器内 overflow求解器耗尽带 trace
B
释放、沉降、采样，再把证据翻译成门控
run_scene_runtime.py 默认 precheck=0，不把不稳初态藏在证据之外。动态 nested source 必须真的碰到声明 target。
0.8终末窗口内声明 support 的接触 fraction 下限
0nested source 接触未声明 target 的 fraction
20 mm静态物体 translation drift 上限
5°resolved rotation error 上限
64 pxhead camera 最小可见像素
30120 帧视频至少需要的互异帧数
攻击测试锁住的误报静态、无接触的 nested support只在少数帧接触nested source 又碰桌面
