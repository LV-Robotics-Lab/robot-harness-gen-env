PEARL / PHYSICAL ASSET RESEARCH
结论检索复用物性 VLA / WAM复现来源

STANDALONE RESEARCH BRIEF · 2026-08-24 · 不是门户报告 · 不是已部署能力

从“长得像”到“动得像”

Text、image、video 如何检索并复用资产？能不能恢复质量、摩擦、关节和材料？VLA 抓得起来，是否就说明它真的“懂物理”？这份报告把三个问题拆开，并给出可以证伪、可以复现的工程路线。

可以恢复一部分但要靠先验 + 已知动作 + 交互轨迹，不是只看一张图。
不必恢复全部只恢复任务会用到的“最小充分物理”。
抓得起 ≠ 参数可读鲁棒策略可以成功，却未必知道质量是几公斤。

先说明证据等级：本页是对一手论文、官方代码和本仓库接口的研究判断。文中“建议复现”均尚未在本仓库跑完；外部论文的结果不能算作 PEARL 自己的实验结果。

想看完整审计：本文件夹同时附带 物理属性检索与重建笔记，以及 VLA / WAM 隐式物理笔记。网页是面向决策的摘要，研究笔记保留逐项来源与限制。

真正可行的“物理重建”是什么？

不是让 LLM 对着外观报一个看似精确的小数，而是逐步缩小不确定性，并用新动作检验它。

推荐定义：先检索一个足够相似、可执行的资产；再为质量、质心、惯量、摩擦、关节和可供性给出有范围的先验；用安全探测动作或已有轨迹做系统辨识；最后只晋升通过任务回放的属性包。
01 · 检索找数字近亲
文字看语义，图片看形状，视频再看运动；记录候选和淘汰理由。
02 · 先验先报范围
VLM、材料表和数据集只提供可能区间，不能直接叫真值。
03 · 探测轻推、抬、倾斜
动作已知，观测位姿、关节、电流、接触或力矩。
04 · 拟合系统辨识
让模拟轨迹贴近观测，并保留多解与置信区间。
05 · 验证换一个动作再考
未参与拟合的任务能复现，才获得任务级物理资格。

Text、image、video 怎么一起检索资产？

不要为三种输入维护三套资产库。它们只是提供不同证据，最终都写进同一个查询和候选清单。

三种输入各自擅长提供什么检索信号
输入先提取什么用来排除什么物理信息边界
Text类别、部件、任务动词、容纳/支撑关系、材料词和尺寸描述语义不符、缺必要部件、许可证不允许、任务能力缺失只给类别和材料先验；不能把“木制”直接变成确定密度或摩擦
Image多尺度视觉特征、轮廓、长宽比、部件 mask、可供性；有标尺/深度时估尺度外形、比例、部件布局或抓取区域差得太远适合几何近亲；单图通常看不出内部质量、质心和接触参数
Video在 image 特征上增加对象跟踪、关节轨迹、形变和动作—结果片段关节轴/限位、运动方式、软硬属性或动态响应不符被动视频只缩小范围；已知动作、标定尺度和力/本体感觉才支持系统辨识
01 · QUERY统一查询
把三种输入归一为语义、几何、运动学、任务和物理覆盖需求。
02 · RECALL宽召回
文本与视觉 embedding 找候选；类别/部件索引补充长尾召回。
03 · GATE先过硬门
许可证、格式、可加载性、尺度、碰撞、必要关节缺一即淘汰。
04 · RERANK按任务重排
语义、形状、部件、运动与 physical coverage 分开计分，禁止黑盒总分。
05 · RECEIPT留候选回执
保存输入/表示 digest、模型版本、候选、许可证、各项分数和淘汰理由。

最关键的复用规则：候选资产只要满足任务所需的几何、运动学和物理资格，就可以复用，不必与输入长得一模一样；只有所有合格候选都耗尽，才进入生成。生成结果也必须回到同一套 manifest 和门禁，不能走旁路。

VLA / WAM 会行动，不等于输出真实物性

这里的 WAM 指 World Action Model（世界—动作模型）。主流模型通常给末端位姿、关节位置或夹爪命令；它们不是直接在说“施加 7 牛顿”，也没有用 SI 单位监督质量和摩擦。

容易误读的说法

“它在新物体上 zero-shot 抓取成功，所以内部一定有可提取的质量、摩擦和惯量变量。”

证据支持的说法

模型学到了足以闭环完成任务的规律；这些规律可能是类别先验、示教动作、反馈纠错、夹爪容错或纠缠的动态表征。

主流动作模型的输出与证据边界
模型典型动作输出直接输出力 / 力矩？能否据此声称恢复物性？
RT-2 / OpenVLA6-DoF 末端增量、夹爪、终止；或 7 维动作 token否否：证明动作泛化，不证明质量/摩擦可读
Octo连续动作 chunk，可按机器人更换动作头否；力矩可作为额外观察否：没有物理参数标定头
π0 / GR00T N1高频动作 chunk；关节或末端配置命令论文未将其作为原生物性输出否：接触任务成功仍可能来自示教和控制器
DreamZero（WAM）联合预测未来视频与连续动作否未来看起来合理，不等于参数与模拟器一致

为什么“只输入图片”也能做动作？训练标签并不只有图片：还有机器人动作，常常还有本体状态；这些数据本身由真实或模拟动力学生成。保守夹紧、慢速运动、位置控制器和每一步重新观察，都能让策略在不知道精确质量的情况下成功。

可以抽 backbone，但先把问题设计成可证伪

不要先假设某个巨大 VLA 内部有一张“物性表”。先测试其表征里是否真的有跨对象、跨外观、跨控制器仍可读的信息。

视觉 / 视频编码器DINO、V-JEPA 2、DINO-WM 或 3DGSim；提供几何和动态先验。
属性分布头输出材料族、质量与摩擦区间，不输出伪精确点值。
交互历史编码器融合 RGB、关节、电流、接触与已知动作。
模拟器拟合层将隐变量约束成有单位、可映射的参数 posterior。
任务验证器用未参与拟合的反事实动作决定是否晋升。
防视觉捷径对象、材质、背景、类别分别留出，不能随机拆视频帧。
和简单基线比类别先验、静态帧、经典系统辨识、oracle 参数都要入场。
测校准而非只测误差报告区间覆盖率、负对数似然和反事实轨迹误差。
允许多解质量、摩擦、控制增益可能产生相近轨迹；posterior 必须保留不确定性。
任务消融若默认参数与 oracle 对某任务无差异，就不值得昂贵重建。
跨后端复核引擎参数名相同也不保证接触行为相同。

最有价值的复现对象

这里的排序看“能否回答我们的核心假设”，而不是只看论文名气。建议先做小而能证伪的实验，再扩大到生成系统。

1

Phys2Real

刚体交互闭环 · P0

为什么：最贴近“3DGS + VLM 先验 + 在线交互辨识”，能直接比较先验、探测后验和域随机化。

首个交付：在平面推任务中随机化摩擦与质心，测 posterior 覆盖率、任务成功和探测次数。

2

PAC-NeRF

视频到材料参数 · P0

为什么：现有代码能从标定多视角视频联合优化几何与连续体材料参数，直接检验 video2env。

首个交付：跑官方物体，导出 material sidecar，再用未拟合的落下/碰撞动作复核。

3

V-JEPA 2 / DINO-WM + Physion++

backbone 可读性 · P0/P1

为什么：低于 14B WAM 的算力风险，能回答视频表征是否含跨分布可读的质量、摩擦、弹性信息。

首个交付：冻结表征做 probe，与 OpenVLA、DINOv2、静态图和从零训练基线比较。

4

PhysX-Anything / PhysX-3D

image2env 结构资产 · P1

为什么：从图像生成几何、关节与物理注释，并能转 URDF/XML；是最直接的 image2env 候选。

首个交付：固定小样本导入 SAPIEN/MuJoCo，测尺度、关节轴、碰撞、settle 与任务回放。

5

PartNet-Mobility + GAPartNet + RBO

关节与交互证据 · P1

为什么：分别补齐“什么会动”“在哪里操作”和少见的 RGB-D + wrench 轨迹。

首个交付：做一个抽屉或柜门的检索、轴/限位估计、把手动作和跨后端开合。

6

主动探测 + 可微拟合

真实机器人标签闭环 · P1

为什么：从根本上解决静态图不可观测，并可把高置信交互标签反哺 image2env。

首个交付：安全的 lift / tilt / push / tap probe，用关节、电流与视频估计任务相关参数。

三个先做的证伪实验

好的实验不只是展示成功案例，还应允许核心想法被否定。

成功抓取是否意味着参数可读？

固定几何与纹理，独立随机化质量、质心、摩擦和控制增益；让 VLA 抓取，再从不同层训练小 probe。

  • 同时报告抓取成功率与 OOD 参数误差
  • 换控制器后仍校准才算有力证据
  • 可能结果：能抓，但读不出参数

哪种观察真正增加信息？

同一对象依次给 text/image、被动视频、已知动作视频、主动 probe + 本体感觉。

  • 每一阶段输出 posterior
  • 比较区间覆盖率和反事实轨迹误差
  • 量化每次交互带来的信息增益

物理属性到底值不值得重建？

对推、抓、开合、软体四类任务比较视觉网格、默认值、类别先验、标定值和 oracle。

  • 任务成功与标定成本画 Pareto 曲线
  • 若默认值不输 oracle，就跳过该属性
  • 把钱花在真正影响行为的参数上

在 PEARL 里怎么落地

保留 scene_gen/ 的稳定边界；物性先验、探测和晋升属于 self-improving 平台层。

目前绝对不能宣称什么

这些边界是报告可信度的一部分。

不能把 LLM 小数叫测量值VLM 只能先验初始化；没有交互或测量，质量、摩擦和内部质心常常不可辨识。
不能把漂亮渲染叫物理证据3DGS、VLM 评分和端点截图不替代连续状态、接触、轨迹与任务 verifier。
不能把 VLA 成功叫参数恢复鲁棒动作、反馈纠错和底层控制器都可能解释成功；要用 probe 和反事实实验区分。
不能把外部论文结果算成 PEARL 结果所有候选复现当前仍是建议；在固定提交、数据、命令和报告落盘前状态是 not_run。
